# Cognitive OS — 可视化 + 成长轨迹 设计文档

> 日期：2026-05-16
> 状态：已确认
> 前置：MVP + Action Layer + Pattern Engine 已完成

## 1. 概述

可视化 + 成长轨迹系统，帮助用户"看见"自己的认知系统。三层架构：

1. **双链增强**：现有文件添加 `[[双链]]` 和结构化标签 → Obsidian 原生图谱/看板/反向链接自动工作
2. **Dashboard Skill**：`/cognitive-dashboard` 生成汇总页面
3. **成长轨迹**：`memory/growth-log.md` 记录阶段性变化和里程碑

## 2. 第一层：双链增强

### 核心思路
在 Agent 写入文件时，自动添加 `[[双链]]` 和结构化标签，让 Obsidian 原生功能自动工作。不需要新增 Skill，而是更新现有 Agent 的写入规则。

### 双链规则

**短期记忆 → 关联认知模式和行为**
```markdown
## 关键对话摘要
识别到 [[完美主义]] 信念，关联模式 [[高压力拖延]]
```

**长期记忆 → 关联触发事件和信念**
```markdown
## 核心信念
- [[必须一次学好]]
- [[失败代表自己不好]]
```

**cognitive-db → 模式间互相关联**
```markdown
## 模式：高压力拖延
### 关联模式
- [[完美主义]]
- [[害怕失败]]
### 关联行动
- [[行为实验-允许不完美]]
```

**actions/ → 关联模式和反馈**
```markdown
### 来源
TEBAR 分析：信念 [[必须一次学好]] → 关联模式 [[高压力拖延]]
```

### 标签体系

| 标签 | 用途 | Obsidian 效果 |
|------|------|--------------|
| `#emotion/焦虑` | 情绪分类 | 按情绪筛选记录 |
| `#pattern/拖延` | 模式分类 | 按模式聚合 |
| `#action/pending` | 行动状态 | 看板视图 |
| `#action/completed` | 行动状态 | 看板视图 |
| `#belief/完美主义` | 信念分类 | 按信念聚合 |
| `#growth/里程碑` | 成长标记 | 成长轨迹页 |

### Obsidian 原生效果
- **图谱**：自动显示模式→信念→行动的关联网络
- **反向链接**：每个信念页面自动列出所有相关记录
- **看板**：`#action/pending` vs `#action/completed` 自动分组
- **搜索**：`tag:#emotion/焦虑` 快速找到所有焦虑记录

### 实现方式
更新现有 Agent 的写入规则：
- Memory Agent 写入时自动添加双链
- Cognitive Agent 写入 cognitive-db 时添加模式间双链
- Action Agent 写入 actions/ 时添加模式关联双链

## 3. 第二层：Dashboard Skill

### /cognitive-dashboard 命令

读取全部数据，生成一个汇总页面 `dashboard.md`，放在 vault 根目录。

### Dashboard 页面结构

```markdown
---
type: dashboard
last_updated: 2026-05-16
generated_by: /cognitive-dashboard
---

# Cognitive OS Dashboard

## 用户画像概览
- 姓名：xxx | 性格：高敏感、完美主义
- 当前恐惧：[[失败被否定]] [[失去掌控感]]
- 核心优势：[[逻辑分析]] [[深度思考]]

## 近期情绪趋势（最近7天）
| 日期 | 情绪 | 强度 | 触发 |
|------|------|------|------|
| 05-16 | 焦虑 | 7/10 | [[考试临近]] |
| 05-15 | 低落 | 5/10 | [[拖延后自责]] |

## 活跃认知模式
- [[高压力拖延]] — 出现 8 次，最近 05-16
- [[完美主义逃避]] — 出现 5 次，最近 05-14

## 待跟进行动
- [ ] 今晚学5分钟（05-16 生成，状态：pending）
- [ ] 行为实验：允许不完美（05-16，状态：running）

## 认知资产统计
- 问题拆解：3 条
- 失败复盘：2 条
- 判断逻辑：4 条
- 方法论：2 条
- 决策路径：1 条
- 认知模式：5 条
- 思维模式：3 条
- 可复用规律：4 条

## 近期成长
- [05-15] 克服了 [[公开演讲]] 恐惧
- [05-10] 发现并记录了 [[高压力拖延]] 模式
```

### Skill 行为
- **触发**：用户手动 `/cognitive-dashboard`
- **读取**：user-profile + 短期记忆(7天) + 长期记忆 + cognitive-db + actions + growth-log
- **输出**：覆盖写入 `dashboard.md`
- **双链**：页面中所有条目都用 `[[双链]]`，点击可跳转到源文件

### 不做什么
- 不自动定期更新（用户手动触发）
- 不做图表（用 Obsidian 插件或 Dataview 做更专业）
- 不做实时监控

## 4. 第三层：成长轨迹

### 存储位置
`memory/growth-log.md` — 与 `user-profile.md` 同级

### 内容结构

```markdown
---
type: growth-log
last_updated: 2026-05-16
total_assessments: 3
---

# 认知成长轨迹

## 阶段评估

### 2026-05 阶段评估
**成长阶段**：思考者 → 构建者过渡期

**突破**：
- 克服了 [[公开演讲]] 恐惧
- 发现并开始干预 [[高压力拖延]] 模式
- 完成行为实验：[[允许不完美实验]]

**仍在挣扎**：
- [[完美主义]] 仍在影响新任务启动
- 深夜情绪低落模式未解决

**认知资产变化**：
- 认知模式：3 → 5（+2 新发现）
- 可复用规律：1 → 4（+3 新提炼）
- 方法论：0 → 2（从实验中抽象）

**下一步方向**：
- 继续行为实验，重点突破完美主义
- 关注深夜低落模式

---

## 成长里程碑

- [2026-05-15] 克服恐惧：[[公开演讲]]
- [2026-05-10] 发现模式：[[高压力拖延]]
- [2026-04-20] 首次自我觉察：识别核心信念 [[必须一次学好]]
- [2026-04-01] 开始使用 Cognitive OS

## 认知模型演化

| 日期 | 模型变化 |
|------|---------|
| 2026-04 | 初始模型：高敏感、低行动启动 |
| 2026-05 | 更新：识别出完美主义为核心驱动力，恐惧从"公开演讲"转为"失败被否定" |
```

### 成长阶段定义

```
记录者 → 思考者 → 构建者 → 主导者

记录者：能记录情绪和事件
思考者：能主动反思和发现模式
构建者：能设计行动实验并执行
主导者：能自主调整认知策略
```

### 生成时机

**定期**：Reflection Agent 每次运行 `/cognitive-review` 时，检查是否到了阶段性评估时间（距上次 ≥7 天）

**手动**：用户可 `/cognitive-dashboard` 后追加"生成长长评估"

**里程碑触发**：当用户克服恐惧、发现新模式、完成行为实验时，自动记录里程碑

### 里程碑自动检测

Reflection Agent 在对话中检测到以下情况时自动记录：
- 恐惧标记为"已克服" → 里程碑
- Pattern Engine 确认新模式 → 里程碑
- 行为实验标记为"成功" → 里程碑
